# Univora

Sito di Univora, progetto di due persone che crea siti web per clienti.

**Infinite possibilità.**

Il sito è composto da `index.html` e dai concept interattivi nella cartella `concepts/`. La sezione Contatti usa ShipMyForm per inoltrare i messaggi a `univorawebsites@gmail.com`; la casella deve confermare l'attivazione del modulo per il dominio pubblicato.
